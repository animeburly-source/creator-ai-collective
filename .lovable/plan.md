
# CreatorOS — Landing Page

Build a stunning, modern landing page inspired by brand24.com's influencer marketing aesthetic. All data will be mock/hardcoded for now.

## Pages & Sections

### Landing Page (`/`)

1. **Hero Section** — Bold gradient background with headline "Find the Perfect Influencers for Your Brand", a search bar ("Search influencers by niche, platform, location..."), and stats badges (500K+ Creators, 20K+ Brands, 2M+ Campaigns)

2. **Creator Categories** — Grid of visually appealing category cards with icons: Gamers, Fitness, Food, Travel, Fashion, Music, Tech, Dance, Comedy, Beauty

3. **Platform Benefits** — 4 feature cards: Discover Creators, Run Campaigns, Track Analytics, Pay Securely — each with icon and short description

4. **How It Works** — 4-step visual flow: Create Campaign → Find Creators → Collaborate → Track Results

5. **Creator Showcase** — Horizontal carousel of featured creator cards showing avatar, name, category, followers, engagement rate, and platform badges (Instagram, YouTube, TikTok)

6. **For Brands / For Creators** — Split section highlighting value propositions for both sides of the marketplace

7. **Testimonials** — Cards with brand and creator quotes

8. **CTA Section** — "Start Your Campaign Today" with email signup and action buttons for Brands and Creators

### Navigation
- Sticky header with logo, nav links (Discover, For Brands, For Creators, Pricing), and Sign Up / Login buttons

### Footer
- Links, social icons, copyright

## Design Direction
- Modern gradient aesthetic (purple/blue/pink tones)
- Clean card-based layouts with subtle shadows
- Smooth scroll animations
- Fully responsive (mobile-first)
- Dark/light sections for visual contrast
